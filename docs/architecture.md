# Початкова архітектура дипломного проєкту

Документ описує поточну архітектуру інформаційної системи управління автосервісом. Початкове рішення створено на C# та .NET 10 із використанням Blazor. Архітектура буде поступово доповнюватися під час реалізації функціональних модулів дипломного проєкту.

## Шари

- **AutoService.Core** — сутності предметної області, переліки, інтерфейси.
- **AutoService.Application** — сценарії використання, бізнес-правила, сервіси.
- **AutoService.Infrastructure** — Entity Framework Core, SQLite, доступ до даних.
- **AutoService.Web** — Blazor, сторінки для клієнтів і працівників, автентифікація.

## Заплановані залежності

- Application → Core
- Infrastructure → Core (і за необхідності Application)
- Web → Application, Infrastructure
- Core не залежить від інших шарів.

## Перенесення попередніх напрацювань

- **sto_project**: зберегти зовнішній вигляд «СТО Рівне», адаптувати HTML/CSS/JavaScript до Blazor.
- **StoRvStar**: перенести перевірену логіку заявок, послуг, кошторисів.
- **CarService**: використати принципи розподілу на шари та доречні патерни.

## Поточний стан

Створено початковий каркас дипломного застосунку на C# та .NET 10.

Реалізовано:

- Файл рішення `AutoService.sln`, який об'єднує чотири проєкти.
- `AutoService.Core` — бібліотека класів для майбутніх моделей предметної області.
- `AutoService.Application` — бібліотека для реалізації бізнес-логіки.
- `AutoService.Infrastructure` — бібліотека для майбутньої роботи з базою даних.
- `AutoService.Web` — початковий Blazor Web App із серверною інтерактивністю.
- Налаштовано посилання між проєктами.
- Перевірено успішну компіляцію всього рішення.
- Перевірено локальний запуск Blazor-застосунку.

Планується реалізувати:

- Моделі клієнтів, автомобілів, заявок і послуг.
- Базу даних SQLite та Entity Framework Core.
- Реєстрацію, авторизацію та ролі користувачів.
- Онлайн-запис на обслуговування.
- Керування заявками на ремонт і кошторисами.
- Перенесення зовнішнього вигляду сайту «СТО Рівне» на Blazor.
- Автоматизоване тестування основних функцій.

Поточний етап — початкова реалізація архітектури та підготовка документації дипломної роботи.
