# Початкова архітектура дипломного проєкту

Це попередня структура. Повноцінні .NET-проєкти, класи та вебсторінки буде додано поетапно.

## Шари
- **AutoService.Core** — сутності предметної області, переліки, інтерфейси.
- **AutoService.Application** — сценарії використання, бізнес-правила, сервіси.
- **AutoService.Infrastructure** — Entity Framework Core, SQLite, доступ до даних.
- **AutoService.Web** — Blazor, сторінки для клієнтів і працівників, автентифікація.

## Заплановані залежності
- Application → Core
- Infrastructure → Core (і за необхідності Application)
- Web → Application, Infrastructure
- Core не залежить від інших шарів.

## Перенесення попередніх напрацювань
- **sto_project**: зберегти зовнішній вигляд «СТО Рівне», адаптувати HTML/CSS/JavaScript до Blazor.
- **StoRvStar**: перенести перевірену логіку заявок, послуг, кошторисів.
- **CarService**: використати принципи розподілу на шари та доречні патерни.

## Поточний стан
Створено лише каталоги та опис архітектури. Проєкти .csproj і запуск застосунку ще не реалізовані.
