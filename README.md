# Інформаційна система управління автосервісом

Дипломна робота 2026/2027 навчального року зі спеціальності 122 «Комп’ютерні науки».

## Мета проєкту

Розробити веборієнтовану інформаційну систему для автоматизації роботи станції технічного обслуговування (СТО). Система має забезпечувати онлайн-запис клієнтів, облік автомобілів, керування ремонтними заявками, послугами, кошторисами та історією обслуговування.

## Заплановані можливості

- Реєстрація та авторизація користувачів із розмежуванням ролей.
- Особистий кабінет клієнта та перелік його автомобілів.
- Онлайн-запис на обслуговування.
- Керування заявками на ремонт і їхніми статусами.
- Каталог послуг та розрахунок вартості робіт.
- Історія обслуговування автомобілів.
- Панель працівника СТО.

## Планований технологічний стек

- **Мова:** C#.
- **Платформа:** .NET 10, ASP.NET Core.
- **Вебінтерфейс:** Blazor.
- **Робота з даними:** Entity Framework Core.
- **База даних:** SQLite.
- **Автентифікація й авторизація:** ASP.NET Core Identity.
- **Інтерфейс:** HTML, CSS, JavaScript.

Остаточний стек узгоджується з керівником дипломної роботи в межах контрольної точки К1.

## Попередні напрацювання

Дипломний проєкт розвиває попередні навчальні проєкти:

- [sto_project](https://github.com/valery2024-2024/sto_project) — вебсайт СТО, розроблений із використанням Flask.
- [StoRvStar](https://github.com/valery2024-2024/StoRvStar) — система керування заявками на ASP.NET Core MVC.
- [CarService](https://github.com/valery2024-2024/CarService) — застосунок на Blazor із багатошаровою архітектурою.

Зовнішній вигляд сайту «СТО Рівне» планується зберегти під час перенесення на Blazor.
